              Frequently Asked Questions

              How do I compress an image to under 50 KB without losing quality?

              Use the Compress Image tool. Enter 50 as the target KB, drop your photo, and it uses binary search to find the highest quality that still fits under 50 KB. The result is as sharp as possible at that file size. All processing happens in your browser — nothing is uploaded.

              How do I resize an image to exact pixel dimensions?

              Use the Resize Image tool. Enter the exact width and height in pixels and the tool resizes and cover-crops to fill those dimensions without stretching. Useful for portal specs like 200×230 or 350×350 pixels.

              Which image formats can I convert between?

              The Convert Format tool supports JPG, PNG, WebP, AVIF, BMP, ICO, and SVG. Many exam portals accept only JPG — if your image is PNG or WebP, converting it to JPG before uploading often resolves a portal rejection.

              Can I remove the background from a photo for free?

              Yes — the AI Background Remover on the AI Tools page uses a neural model (U²-Net) running entirely in your browser. It works on people, products, and complex edges including hair. The model downloads once and is cached — no file is sent to any server.

              How do I create a favicon from my logo?

              Use the Favicon Generator tool. Drop your logo image (PNG works best) and it generates a multi-layer .ico file (16, 32, and 48px) plus individual PNGs for your PWA manifest. Place the .ico in your website's root folder.

              Is it safe to use these tools with personal photos or ID documents?

              Yes. Every tool on this page runs entirely in your browser using the Canvas API and Web Workers. Files are never sent to any server. Open browser DevTools (F12), go to the Network tab, and use any tool — you will see zero outbound file requests.
