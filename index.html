Frequently Asked Questions

How do I resize my photo for SSC CGL?

SSC CGL requires a photograph of 200×230 pixels (estimated from 3.5×4.5 cm at 200 DPI), between 20–50 KB, in JPG format. Use the Application Pack, select SSC from the portal list, and drop your photo — it resizes and compresses automatically to the exact spec.

What are the photo size requirements for UPSC Civil Services?

UPSC Civil Services requires a photograph of 350×350 pixels, between 40–100 KB, in JPG format. The signature must be 350×150 pixels, between 10–40 KB. UploadSure's Application Pack fixes both automatically when you select the UPSC portal.

How do I compress a photo to under 50 KB without losing quality?

Use UploadSure's Compress Image tool. Enter 50 as the target size in KB, drop your photo, and the tool uses binary search to find the highest quality that still fits under 50 KB. The result is as sharp as possible at that file size. All processing happens in your browser — no upload required.

Is it safe to use UploadSure with my Aadhaar card or PAN card?

Yes. UploadSure processes all files entirely in your browser using the Canvas API and Web Workers. Your files are never sent to any server — you can verify this yourself by opening browser DevTools (F12), going to the Network tab, and uploading a file. You will see zero outbound file requests. The processing happens in your device's RAM and is discarded when you close the tab.

Why does the portal keep rejecting my photo even after I resize it?

Common reasons beyond size: (1) Format — some portals accept only JPG, not PNG or WebP. Use the Convert tool to ensure the format is correct. (2) File size — portals check both minimum and maximum KB, not just maximum. (3) Background colour — passport-style portals often require a plain white background. (4) The portal may use Live Capture (webcam) instead of file upload for some exams, which sets dimensions automatically. The Application Pack flags which specs are estimated versus confirmed.
