    Frequently Asked Questions

    How do I merge multiple PDF files into one?

    Use the Merge PDF tool. Drop multiple PDF files, drag the rows to set the order you want, then click Merge PDFs. The result is a single PDF with all pages combined in your chosen order. Text stays selectable — pages are not rasterised. Everything runs in your browser and no file is uploaded to any server.

    How do I compress a PDF to a smaller file size?

    Use the Compress PDF tool. Choose Low to keep text selectable (lossless re-save), Medium or High to rasterise pages at reduced scale, or Custom Size to enter a target KB and the tool finds the best quality that hits that size. All processing runs in your browser — the file is never uploaded.

    How do I split a PDF into separate pages?

    Use the Split PDF tool. Drop your PDF, then enter a page range (for example 1–3 to extract pages 1 to 3) or click individual page thumbnails to select them. The tool extracts only the pages you chose and downloads the result as a new PDF.

    How do I add a digital signature to a PDF?

    Use the Sign PDF tool. Drop your PDF, then drop a signature image (PNG with transparent background works best). Choose which page to place it on and its position. Note: this is a visual placement, not a legally-binding cryptographic e-signature — suitable for internal documents and most portal submissions.

    Is it safe to use these PDF tools with government documents?

    Yes. All PDF operations run entirely in your browser using pdf-lib and pdf.js — no file is uploaded to any server. You can verify this: open browser DevTools (F12), go to the Network tab, and drop a PDF — you will see zero outbound file requests. The file stays in your device's RAM and is discarded when you close the tab.

    How do I compress a PDF for a government portal upload?

    Use the Compress PDF tool and choose Custom Size. Enter the portal's maximum file size in KB (for example 500 for a 500 KB limit). The tool automatically finds the highest quality that fits under that limit. For portals that require text to stay selectable, choose Low compression instead.
